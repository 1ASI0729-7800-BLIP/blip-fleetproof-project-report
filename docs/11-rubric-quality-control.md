# Control de Calidad de Rúbrica

## Objetivo

Este control asegura que el informe, la presentación, los videos y los repositorios de BLIP cumplan la rúbrica oficial antes de cada entrega.

## Curso y outcome evaluado

| Elemento | Valor oficial |
|---|---|
| Curso | 1ASI0729 Desarrollo de Aplicaciones Open Source |
| Student Outcome | ABET - EAC - Student Outcome 3 |
| Criterio central | Capacidad de comunicarse efectivamente con un rango de audiencias. |

## Reglas de redacción

- Usar tono técnico, claro y formal.
- Mantener nombres de artefactos oficiales en inglés cuando la guía los define así.
- Redactar User Stories y Acceptance Criteria como texto editable, no como capturas.
- Usar porcentajes solo cuando provengan de entrevistas o fuentes verificables.
- Citar fuentes en formato APA cuando respalden datos, mercado o decisiones técnicas.

## Reglas de evidencia

- Cada sección con imagen debe incluir explicación, no solo captura.
- Cada avance de implementación debe tener rama, commit, Pull Request, merge y captura.
- Cada release debe tener etiqueta, descripción y evidencia en GitHub.
- Cada video debe tener screenshot, URL, timing y duración.
